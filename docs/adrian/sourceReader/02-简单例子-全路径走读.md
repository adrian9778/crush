# 简单例子全路径走读：`crush run "Hello"`

> **场景**：用户执行 `crush run "Hello"` —— 非交互模式，发送一条简单 prompt，获得纯文本回复，不触发任何工具调用。
> **时间**：2026-08-27 (CST)
> **版本**：Crush @ main branch, Go 1.26.6, charm.land/fantasy v0.41.2
> **阅读说明**：本文只讲主成功路径，异常和边界暂不展开。所有文件路径相对于项目根目录。

## 1. 场景描述与输入输出

**命令：**

```bash
crush run "Hello"
```

**输入：**

- 命令行参数：`run`（子命令）、`"Hello"`（prompt）
- 配置文件：`~/.config/crush/crushrc` 或 `./crushrc`（假设已配置 LLM provider）
- 数据目录：`./.crush/`（SQLite 数据库、日志）

**输出：**

```text
Hello! How can I help you today?
```

（输出到 stdout，随后进程退出）

**前提条件：**

- 至少一个 LLM provider 已配置（如 Anthropic API Key）
- 工作目录可写（用于 `.crush/` 数据目录）

## 10. Step 8：消息存储与事件流

```
internal/message/message.go
函数：Update（Service 实现）
```

`message.Service.Update` 实现：

1. 将消息状态写入内存缓冲区
2. 防抖窗口（33ms）内合并多次更新
3. 到达窗口或终端状态时写入 SQLite
4. 发布 `pubsub.UpdatedEvent` 事件

```
internal/message/message.go
Const：defaultUpdateDebounce
值：33 * time.Millisecond
```

事件流：

```text
message.Service.Update()
  │
  ├──→ SQLite (写入消息内容)
  │
  └──→ pubsub.Broker.Publish(UpdatedEvent, Message)
         │
         ├──→ app.events (主事件总线)
         │      │
         │      └──→ app.RunNonInteractive 的 messageEvents channel
         │
         └──→ app.Subscribe → TUI（交互模式时）
```

## 11. Step 9：输出到 stdout 并退出

回到 `app.RunNonInteractive` 的事件循环：

```
internal/app/app.go
函数：RunNonInteractive
偏移：+119 ～ +170
```

事件循环：

```go
for {
    select {
    case result := <-done:          // agent 运行完成
        stopSpinner()
        return nil
    case event := <-messageEvents:  // 消息事件
        // 写入 stdout
        content := msg.Content().String()
        part := content[readBytes:]
        fmt.Fprint(output, part)
    case <-ctx.Done():              // 取消
        return ctx.Err()
    }
}
```

**具体流程：**

1. `messageEvents` channel 收到 assistant message 事件
2. 检查 `msg.Role == message.Assistant` 且 `msg.SessionID == sess.ID`
3. 计算增量内容 `content[readBytes:]`
4. `fmt.Fprint(os.Stdout, part)` 输出到 stdout
5. 更新 `readBytes` 游标
6. `done` channel 收到结果 → 返回

**RunComplete 事件：**

`sessionAgent.Run` 的 defer 中发布 `RunComplete` 事件：

```
internal/agent/agent.go
函数：Run（sessionAgent）
偏移：+186 ～ +215（defer 块）
```

该事件携带最终的 assistant message ID 和完整文本，确保非交互客户端能可靠地收到完整输出。

**退出：**

`RunNonInteractive` 返回 → `runCmd.RunE` 返回 → `main` 退出。

**最终输出：**

```text
Hello! How can I help you today?
```
