## 1. 调用关系总览

```mermaid
sequenceDiagram
    participant U as 用户
    participant M as main.go
    participant CMD as cmd/root.go
    participant RUN as cmd/run.go
    participant WS as workspace
    participant APP as app.App
    participant CO as Coordinator
    participant SA as sessionAgent
    participant FAN as fantasy.Agent
    participant LLM as LLM Provider
    participant MSG as message.Service
    participant DB as SQLite
    participant PS as PubSub

    U->>M: crush run "Hello"
    M->>CMD: Execute()
    CMD->>RUN: runCmd.RunE
    RUN->>WS: setupLocalWorkspace()
    WS->>APP: app.New(ctx, conn, store, skills)
    APP->>CO: NewCoordinator(opts)
    CO->>SA: buildAgent() → sessionAgent
    RUN->>APP: RunNonInteractive(ctx, stdout, "Hello", ...)
    APP->>CO: Run(ctx, sessID, "Hello")
    CO->>SA: Run(ctx, SessionAgentCall)
    SA->>MSG: Create(user message)
    MSG->>DB: INSERT message
    SA->>FAN: Agent.Stream(prompt="Hello")
    FAN->>LLM: HTTP POST /messages (SSE)
    LLM-->>FAN: streaming text chunks
    FAN->>SA: OnTextDelta("Hello!")
    SA->>MSG: Update(assistant message)
    MSG->>DB: UPDATE message
    MSG->>PS: Publish(UpdatedEvent)
    PS-->>APP: messageEvents channel
    APP->>U: fmt.Fprint(stdout, "Hello!")
    SA->>PS: Publish(RunComplete)
    PS-->>APP: done channel
    APP-->>U: return (exit)
```

**fantasy.Agent.Stream 内部逻辑（第三方库）：**

1. 将 system prompt + history + prompt 打包为 provider-specific 请求格式
2. 发送 HTTP 请求到 LLM API（如 Anthropic `POST /v1/messages`）

6. 如果 `finish_reason == stop`，返回 `AgentResult`

```text

  │     ├── text_delta "Hello"     → OnTextDelta()
  │     ├── text_delta "!"         → OnTextDelta()
  │     ├── text_delta " How can"  → OnTextDelta()
  │     ├── text_delta " I help"   → OnTextDelta()
```

```go
case event := <-messageEvents:
    msg := event.Payload
    if msg.SessionID == sess.ID && msg.Role == message.Assistant && len(msg.Parts) > 0 {
        content := msg.Content().String()
        readBytes := messageReadBytes[msg.ID]
        part := content[readBytes:]
        if readBytes == 0 {
            part = strings.TrimLeft(part, " \t")
        }
        if printed || strings.TrimSpace(part) != "" {

        }
        messageReadBytes[msg.ID] = len(content)
    }
```
